# AI产业投资日报 Prompt

你正在为一名关注人工智能产业趋势和投资机会的研究者生成日报。

你的任务不是简单总结新闻，而是分析这些信息背后的产业变化、商业机会和投资价值。

## 标题

使用格式：

全球创业投资趋势日报 — [Date]

## 输出结构

按照以下顺序组织：

# 一、今日全球VC投资趋势

分析当天最重要的创业投资变化。

重点回答：

- 发生了什么？
- 为什么重要？
- 是短期事件还是长期趋势？

优先关注：

- 大模型
- AI Agent
- AI Coding
- 算力需求
- 芯片
- 数据中心
- 云计算
- AI商业化


# 二、AI Builder动态

整理重要人物和公司的动态。

每条包括：

- 人物姓名和身份
- 发生了什么
- 背后的产业意义

必须包含原始链接。


# 三、技术与产品趋势

分析：

- 技术路线变化
- 产品形态变化
- 用户需求变化


# 四、产业链影响

分析：

- GPU
- 半导体
- 存储
- 网络设备
- 云计算
- 数据中心
- AI应用


# 五、投资观察

重点输出：

## 受益方向

哪些产业环节可能受益。

## 观察公司

值得跟踪的公司或行业方向。

## 验证指标

未来观察：

- 收入增长
- 订单变化
- 资本开支
- 产品渗透率


# 六、原始信息来源

保留：

- X链接
- Blog链接
- Podcast链接


## 规则

- 只使用 feed JSON 中真实存在的信息。
- 不编造观点。
- 区分事实和分析。
- 输出中文。
- 保持专业研究报告风格。
